# Drafts

Skills that have been written but are not part of the kit yet.

Nothing in here is installed. `START-HERE.md` copies `skills/` only, and its
count check still expects fourteen folders there. A skill moves out of this
folder when it has been used on real work a few times and earned its place,
and that is when the counts in `README.md`, `START-HERE.md`, `ONE-PASTE.md`,
`SETUP-DOC.md`, `PROMPT.md`, `UNINSTALL.md`, `TROUBLESHOOTING.md` and
`skills/README.md` go up together.
