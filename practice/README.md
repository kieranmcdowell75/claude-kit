# The practice guides

Eight short guides. None of them are setup — setup is `START-HERE.md`. These are
the habits that decide whether this is still useful in month three.

**Read these two during setup** (the prompt tells Claude to):

- `folders-and-memory.md` — one folder per business, and why memory doesn't follow you
- `the-permission-modes.md` — what each mode does and which one to sit in

**Read this one when setup is finished:**

- `where-to-start.md` — what to connect, what to build first, and what good looks like

**The rest, when you hit the thing they're about:**

- `connecting-your-tools.md` — how a connection actually goes, and what to do when it won't
- `memory.md` — what belongs in a memory, what doesn't, and how to build one worth having
- `choosing-a-model.md` — when the faster one is fine and when it isn't
- `long-jobs-and-handovers.md` — jobs that outlast one session, and handing over cleanly
- `using-it-from-your-phone.md` — running something while you're not at the desk

You don't need to read them in order, and you don't need to read them all.
