# What the words mean

You'll hear these while connecting things. None of them need understanding to use
this — but it helps to know you're not missing something.

**API** — a proper doorway into a piece of software, built for other software to
use. When a system has one, connecting is reliable and fast. When it doesn't,
Claude has to work the screens like a person would, which works but is slower and
breaks when the company redesigns their site.

**Connector / integration** — a ready-made connection to a well-known product.
If one exists for your software, it's the easy path. Many business systems don't
have one yet.

**Token / API key** — a long password that software uses instead of a username.
Yours live in settings, never in the session. If anyone asks you to paste one into a
conversation, stop and ask why.

**Read-only vs write access** — read-only means Claude can look but not change
anything. Write access means it can change things. Always start read-only.

**Rate limit** — how much a system lets you ask for in a day. Go over and it stops
answering until tomorrow, which usually happens mid-job.

**Skill** — a short set of instructions Claude reads when a particular job comes
up. You don't call them by name; they fire when they're relevant.

**Folder (connected)** — the folder you've pointed Claude at. It can see
everything inside and nothing outside. It's also where it keeps what it learns
about that business.

**CLAUDE.md** — a plain text file of house rules. The one in your home folder is
how Claude behaves everywhere. The one in a business folder is about that business.
Same name, different jobs.

**Memory** — the notes Claude keeps about your business as you work. Saved against
the folder you had connected, and loaded automatically next time.

**Handover** — a written summary that lets a fresh conversation carry on where the
last one stopped. Sessions get worse as they get long; this is how you escape that.

**Session / chat** — one conversation. Starting a new one clears the slate, which
is sometimes exactly what you want.

**Export** — the download button almost every system has. Often the fastest way
in, and the one the company actually expects you to use.

**Node** — a free background tool that a lot of software connections are built
on. You never open it or look at it. Claude installs it during setup because
without it, many of the connections you'll want later simply won't run.

**Git** — a free background tool that keeps track of changes to files, so you can
go back to how something was last week. Claude installs it during setup and asks
for your name and email, because it refuses to save anything until it knows who
you are. You never have to use it directly.

**Python** — the language Claude writes in when it needs to work through your
data. You never see it or touch it. Macs come with a limited version that isn't
enough, which is why setup installs a proper one.

**Playwright** — a free tool that lets Claude work a website the way you would:
click, type, read what's on screen. Needed for any system that has no proper
connection. It keeps its own browser profile, so once you sign in to something you
stay signed in.

**MCP** — the standard way Claude plugs into other software. You'll see it
mentioned. You never need to care what it stands for.
