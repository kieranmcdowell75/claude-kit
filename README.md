# The Claude Kit

Everything needed to turn a fresh Claude install into something that actually runs
a business. Built by Kieran McDowell from three months of doing it to his own.

Working name. Rename it to whatever you want to call this.

## Who it's for

A business owner or team member who is not technical, has never written code, and
wants Claude connected to their real systems doing real work.

## What's in it

| Folder | What it is |
|---|---|
| `START-HERE.md` | The one thing a new person pastes into Claude. It runs the setup. |
| `house-rules/` | How Claude should talk and behave. Plain text, no install. |
| `practice/` | The habits that make the difference. Read once, use forever. |
| `skills/` | Fourteen skills that come with the kit, plus the ones you'll add. |
| `CLAUDE-md-template.md` | The house-rules file each business folder gets. |
| `GLOSSARY.md` | What the words mean, when you hit one you don't know. |
| `TROUBLESHOOTING.md` | When something isn't working. Start here. |
| `UNINSTALL.md` | Removing it, or resetting a machine for someone else. |

## What it deliberately does not contain

No downloads from a private server. No licence keys. No account to sign up for.
No library of two hundred skills nobody uses.

Everything here is a file you can read, change, and hand to someone else. If a
part of it stops working, you can see why.

## The idea behind it

Most Claude setups fail because people install a lot and then don't change how
they work. The order that actually works:

1. Teach it how you want to be spoken to.
2. Connect it to your real systems.
3. Give it a folder per business, and house rules in that folder.
4. Add a skill only when a real job needs one.

Steps one to three take an afternoon and cover most of the value. Step four never
ends, and that's fine.
